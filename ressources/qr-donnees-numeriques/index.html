1. Comprendre les données d'un QR code

Un QR code n'est pas forcément une adresse Internet

Un QR code est une façon de représenter des données sous forme de petits carrés noirs et blancs. Un lecteur peut retrouver le texte ou les informations qui y sont codés.

Ce contenu peut être une adresse de site, une fiche de contact, des paramètres Wi-Fi ou un autre type d'information. Ce n'est pas le QR code lui-même qui décide où placer les données : c'est le logiciel qui les interprète.

📝 Champs organisés→▦ QR code ou fichier→📱 Application du téléphone

Des champs plutôt qu'un texte en vrac

Dans une fiche contact, le prénom, le nom, la société, le téléphone et le courriel doivent être rangés dans des champs différents. Un texte qui contient simplement « Julie Martin 01 23 45 67 89 » ne suffit pas à garantir une importation correcte.

vCard (.vcf)Échanger une fiche contact structurée.
iCalendar (.ics)Échanger un événement de calendrier.

Une règle de sécurité

Les informations d'un QR code ne sont pas nécessairement secrètes. Toute personne capable de scanner un QR code affiché peut en lire le contenu. N'y place jamais un mot de passe personnel ou des coordonnées privées sans autorisation.

J'apprends : comment est organisée une vCard ?

Le format vCard contient des propriétés portant chacune une signification précise. N sépare le nom du prénom, FN fournit le nom affiché, ORG décrit l'entreprise, TITLE la fonction, TEL le numéro et EMAIL l'adresse électronique.

BEGIN:VCARD
VERSION:3.0
N:Martin;Julie;;;
FN:Julie Martin
ORG:CyberNet;Service technique
TITLE:Technicienne réseau
TEL;TYPE=WORK,VOICE:+33123456789
EMAIL;TYPE=WORK:julie.martin@example.com
END:VCARD

3. Mission 2 : ajouter un rendez-vous

Situation professionnelle

Une intervention réseau est programmée dans une entreprise. Ton responsable t'envoie un événement prêt à importer. Le fichier doit contenir la date, l'horaire, le titre, le lieu et une description.

DÉC.03
Intervention réseau : exercice CIELJeudi 3 décembre 2026, 14 h à 15 h (Paris)Salle technique, entreprise fictive
J'apprends : à quoi sert un fichier ICS ?

Le format iCalendar (.ics) décrit un événement qui peut être lu par différentes applications d'agenda. SUMMARY contient le titre, DTSTART le début, DTEND la fin, LOCATION le lieu et DESCRIPTION la description.

Dans le fichier d'exemple, les heures sont enregistrées en UTC pour correspondre à 14 h et 15 h en France métropolitaine le 3 décembre (heure d'hiver).

4. Mission 3 : connecter un smartphone au Wi-Fi

Situation professionnelle

Un technicien prépare un point d'accès dédié à un atelier de formation. Les appareils doivent rejoindre le réseau sans recopier manuellement un mot de passe long.

Sur place, l'enseignant peut configurer un point d'accès d'exercice isolé avec les paramètres ci-dessous. À distance, tu peux analyser le QR code, mais tu ne pourras pas vérifier une connexion à un réseau qui n'existe pas chez toi.

Nom du réseau (SSID)CIEL-LAB-EXEMPLE
SécuritéWPA2-Personal compatible
Clé de l'exerciceMotDePasseFictif2026!
J'apprends : les trois informations nécessaires

Le SSID identifie le réseau sans fil. Le mode de sécurité indique la méthode utilisée par le point d'accès. La clé permet de rejoindre un réseau protégé par mot de passe personnel lorsque l'appareil est compatible.

Le QR code ci-dessous contient ces informations sous forme de texte structuré, avec le préfixe WIFI:. Ce format ne remplace pas l'authentification par identifiant individuel d'un réseau d'entreprise WPA-Enterprise.

WIFI:T:WPA;S:CIEL-LAB-EXEMPLE;P:MotDePasseFictif2026!;H:false;;
Je me teste : scanner puis se connecter

Si un point d'accès d'exercice a été préparé avec exactement ces paramètres, affiche le QR code sur un autre écran et scanne-le depuis ton smartphone. Confirme la connexion proposée.

Une même logique, trois applications

Le contact, le rendez-vous et les paramètres Wi-Fi utilisent des informations organisées. Le fichier ou le QR code transporte les données, puis le téléphone les interprète pour proposer une action.

ContactPrénom, nom, fonction, téléphone, courriel.
AgendaDate, début, fin, titre, lieu.
Wi-FiNom du réseau, sécurité, clé.
