# Manuel d'utilisation du tableau d'adressage IPv4

Site web pédagogique autonome — brouillon v0.1.

## Installation

Décompresser le ZIP puis copier **tout le contenu du dossier** sur le serveur web (NAS Synology, hébergement statique ou GitHub Pages). Ouvrir `index.html`. Aucun PHP, aucune dépendance, aucune connexion Internet ne sont nécessaires.

## Structure

- `index.html` : contenu pédagogique, étapes 1 à 5.
- `assets/style.css` : mise en page responsive et thèmes clair/sombre.
- `assets/app.js` : tableaux binaires et révélations progressives.
- `docs/Mode_emploi_tableau_adressage_IPv4_COMPLET.pdf` : PDF original téléchargeable.

## Périmètre

Reprise de la méthode du manuel original : 1 uniquement dans les cases, CIDR et barre, quatre adresses, astuce de Pépette, décimal, exemple 172.19.86.173/27. Extension FLSM avec 192.168.10.0/24 découpé en quatre /26. Ni VLSM ni IPv6.

## Limites de cette première version

Exemples fixes et guidés, pas encore de fiche A3 interactive ni de thème Tron. Le chapitre FLSM constitue une première proposition pédagogique à confronter à la fiche A3 exacte. La version PDF disponible est provisoirement le document original.
