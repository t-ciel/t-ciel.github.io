1. Relier les équipements

Qu'est-ce qu'Ethernet ?

Ethernet est une famille de technologies de réseau local définies notamment par IEEE 802.3. On la rencontre sur des câbles cuivre à paires torsadées, des fibres optiques et des équipements réseaux de nombreux débits.

Pour les liaisons cuivre courantes, l'équipement utilise une interface Ethernet et un câble adapté, souvent avec un connecteur modulaire 8P8C familièrement appelé RJ45.

Du câble à la liaison

Un câble correctement raccordé est nécessaire, mais pas toujours suffisant : deux équipements doivent aussi négocier une liaison compatible, avec des paramètres adéquats. Les voyants de port renseignent sur l'état du lien.

Un panneau de brassage ne commute pas les trames. Il relie passivement ses prises avant et arrière ; c'est le switch qui prend des décisions de transfert.

2. Les adresses MAC et les trames

Identifier l'émetteur et le destinataire

Une trame Ethernet transporte notamment une adresse MAC de destination, une adresse MAC source, un champ type/longueur, des données et une séquence de contrôle d'erreurs (FCS). Les adresses MAC classiques font 48 bits.

Une adresse MAC ne remplace pas une adresse IP. Ethernet traite une livraison locale ; IP sert à acheminer des paquets entre réseaux.

Le broadcast

Une destination MAC FF:FF:FF:FF:FF:FF désigne un broadcast Ethernet : un switch le diffuse généralement vers les autres ports du même domaine de diffusion/VLAN, sans le renvoyer au port d'entrée.

Un switch ne distribue pas systématiquement toutes les trames à tous les ports. Pour une destination unicast connue, il sélectionne le port appris.

3. La table MAC du switch

Comment apprend-il ?

À la réception d'une trame, le switch enregistre l'adresse MAC source et le port d'entrée dans sa table. Si la destination est connue, la trame est transmise vers le port correspondant. Sinon, elle est diffusée dans le VLAN concerné.

La table MAC change lorsque des équipements se déplacent ou lorsque des entrées expirent. Une trame reçue n'enseigne pas automatiquement au switch où se trouve sa destination.

Ne pas confondre les machines

Le switch travaille principalement avec les adresses MAC. Le routeur utilise les adresses IP pour communiquer entre réseaux. Un point d'accès assure une liaison Wi-Fi avec des appareils sans fil.

Le cours sur les VLAN approfondira la séparation des domaines de diffusion, sans supposer qu'un switch non administrable peut configurer des VLAN.
