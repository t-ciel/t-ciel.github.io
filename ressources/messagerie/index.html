Messagerie d'entreprise

1. La messagerie en entreprise

Quand Camille envoie un courriel, son ordinateur le transmet d'abord à un serveur de messagerie. Celui-ci remet le courriel au serveur du destinataire. Le destinataire peut ensuite le lire sur son ordinateur ou son téléphone.

Le trajet d'un courriel

💻PC de CamilleÉcriture et envoi
→SMTP 587
🖥️Serveur expéditeurRemet le message
→SMTP 25
🖥️Serveur destinataireReçoit et stocke
→POP3, IMAP ou web
📱DestinataireConsulte sa boîte

Le courriel passe par des serveurs. Il ne va pas directement d'un ordinateur à l'autre. Le DNS aide à trouver le serveur qui reçoit les courriels du domaine grâce à un enregistrement MX.

Qui fait quoi ?

Le client de messagerie est le logiciel ou l'application utilisé pour écrire et lire les courriels. Le serveur de messagerie reçoit, conserve et transmet les messages. Ce serveur peut être installé dans l'entreprise ou hébergé par un prestataire.

Exemple : Camille envoie un courriel à un client extérieur. Même si les deux PC sont allumés, ils ne communiquent pas directement entre eux pour transférer ce courriel.

À retenir : le logiciel sert à lire et écrire ; les serveurs servent à transporter et conserver les courriels.

2. Les clients de messagerie

Un client de messagerie peut être Outlook, Thunderbird, l'application mail d'un smartphone ou un webmail accessible dans un navigateur. Une même adresse mail peut être utilisée sur un PC et un téléphone. Le fournisseur doit autoriser les méthodes de connexion choisies.

Une adresse mail sur plusieurs appareils

Exemple : Camille consulte son adresse professionnelle sur son PC et sur son téléphone. Les deux appareils peuvent afficher les mêmes messages. Selon leurs réglages, un message lu sur le téléphone n'est pas forcément marqué comme lu sur le PC. Nous verrons pourquoi dans les chapitres POP3 et IMAP.

Selon la configuration, les courriels peuvent être conservés sur le serveur, sur le PC ou sur les deux. Avant de remplacer un ordinateur, le technicien doit savoir où se trouvent les anciens messages.

Et le webmail ?

Un webmail permet de lire ses courriels dans un navigateur, comme avec Gmail sur le Web. On se connecte au site du fournisseur, généralement avec une connexion sécurisée HTTPS. Il n'est pas nécessaire d'installer Outlook ou Thunderbird.

3. Envoyer les courriels : SMTP

SMTP sert à envoyer des courriels. Quand on clique sur « Envoyer », le logiciel transmet le message à un serveur. Ce serveur l'achemine vers le serveur du destinataire.

Client → serveur d'envoi : SMTP, port 587 (STARTTLS)
Serveur → serveur : SMTP, port 25
Autre cas autorisé : port 465 (TLS implicite)

Le logiciel utilise souvent le port 587 pour envoyer un courriel avec un compte identifié. Entre deux serveurs de messagerie, on utilise généralement le port 25. Le port 465 est une autre possibilité pour l'envoi sécurisé. Le technicien doit toujours suivre les paramètres du fournisseur.

Où se trouve le message envoyé ?

SMTP transporte le courriel, mais ne décide pas où garder une copie dans « Envoyés ». Le logiciel peut la garder localement ou la placer dans le dossier « Envoyés » du serveur. Avec un compte IMAP correctement configuré, ce dossier peut être synchronisé.

Exemple : un photocopieur peut envoyer un document numérisé par courriel grâce à SMTP. Pour le configurer, le technicien vérifie le serveur d'envoi, son port et le compte autorisé.

Attention : utiliser le compte mail personnel d'un salarié sur un photocopieur peut poser des problèmes de confidentialité. Nous reviendrons sur ce point au chapitre 6.

4. Recevoir les courriels : POP3

Avec POP3, le logiciel télécharge les courriels sur l'ordinateur. Il peut ensuite les conserver et les classer localement. Les dossiers ne sont pas synchronisés automatiquement entre plusieurs appareils.

POP3 : TCP 110 (possible avec STARTTLS selon service)
POP3S : TCP 995 (TLS implicite)

Après le téléchargement, le logiciel peut laisser une copie sur le serveur ou la supprimer. Cela dépend d'un réglage. Avant de changer de PC, le technicien doit vérifier ce réglage et sauvegarder les courriels qui ne sont conservés que localement.

Exemple : un technicien remplace le PC d'un agent de maintenance. Les anciens courriels sont enregistrés sur ce PC et ne sont plus sur le serveur. Il doit les sauvegarder avant le remplacement.

Une boîte utilisée par plusieurs personnes

Avec POP3, un courriel supprimé ou rangé dans un dossier sur un PC n'est pas automatiquement supprimé ou rangé sur le deuxième PC.

5. Synchroniser ses courriels : IMAP

Avec IMAP, les courriels et les dossiers restent sur le serveur de messagerie. Le PC et le téléphone affichent la même boîte. Quand on lit, classe ou supprime un message sur un appareil, les autres retrouvent normalement le changement après synchronisation. Une copie temporaire peut aussi être conservée sur les appareils.

IMAP : TCP 143 (STARTTLS possible)
IMAPS : TCP 993 (TLS implicite)

Et les messages envoyés ?

Ils peuvent également être synchronisés. Le logiciel envoie le courriel par SMTP. Il peut ensuite garder une copie dans le dossier « Envoyés » sur le serveur IMAP. Dans ce cas, le PC et le téléphone retrouvent le même message envoyé. Si la copie reste uniquement sur le PC, elle n'apparaît pas sur le téléphone.

Exemple : un message envoyé depuis le téléphone n'apparaît pas dans « Envoyés » sur le PC. Le technicien vérifie si les deux appareils utilisent bien le dossier « Envoyés » du serveur.

Le cas des configurations mixtes

Une même adresse peut être utilisée en POP3 sur un PC et en IMAP sur un téléphone, si le fournisseur le permet. Si le PC supprime les courriels du serveur après les avoir téléchargés, le téléphone risque de ne plus les retrouver.

À retenir : IMAP synchronise la messagerie, y compris les envoyés si le dossier est sur le serveur. Les calendriers partagés et les droits d'accès nécessitent d'autres services, étudiés au chapitre 6.

6. Les plateformes collaboratives

Microsoft 365 (avec Exchange Online) et Google Workspace ne servent pas seulement à envoyer des courriels. Ces plateformes peuvent aussi proposer des calendriers communs, des contacts et des boîtes mail partagées, selon l'abonnement.

On peut lire les messages depuis un navigateur ou une application compatible. Le navigateur utilise généralement HTTPS. Entre serveurs, les courriels continuent de circuler avec SMTP.

Pourquoi payer davantage qu'une boîte IMAP ?

Avec IMAP, on peut synchroniser les courriels reçus et envoyés. Microsoft 365 n'est donc pas nécessaire pour ce seul besoin. Une plateforme collaborative est surtout utile quand les salariés doivent partager des calendriers, des contacts, des boîtes mail ou des droits d'accès.

Exemple : trois techniciens du SAV utilisent la boîte commune sav@entreprise.fr. Ils peuvent consulter les demandes des clients. Un responsable décide quels techniciens ont le droit de lire ou de répondre. Ils peuvent aussi partager un calendrier.

Un compte Exchange peut-il aussi utiliser IMAP ?

Oui, si l'administrateur autorise IMAP et la méthode de connexion nécessaire. Il faut donc regarder les paramètres de l'appareil avant de dépanner.

Attention aux photocopieurs

Un photocopieur peut envoyer des scans avec SMTP, même s'il ne sait pas utiliser les fonctions Microsoft 365. Le technicien ne doit pas choisir au hasard le compte personnel d'un salarié : celui-ci pourrait retrouver des documents confidentiels parmi les messages envoyés. Il faut utiliser une solution autorisée par l'entreprise.

7. Choisir une offre de messagerie

Quand une entreprise choisit une messagerie, elle compare les services proposés : taille de la boîte, accès sur PC et téléphone, webmail, sauvegardes, assistance et fonctions de partage.

Comparer les besoins

BesoinMessagerie hébergée simplePlateforme collaborative
Courriels multi-appareilsOui avec IMAP correctement configuréOui
Calendriers partagés intégrésSelon services complémentairesGénéralement proposés
Gestion avancée des droitsSelon le fournisseurGénéralement proposée
TarifSouvent moins élevéVariable selon les licences et services

Évaluer le coût réel

Une offre peu chère peut convenir si l'entreprise a seulement besoin de courriels. Une offre plus chère peut être utile si les salariés partagent des calendriers ou des boîtes. Il faut aussi tenir compte de l'espace disponible, des sauvegardes et de l'assistance.

Exemple de comparaison pour 20 salariés :
Offre fictivePrix par salarié / moisPrix pour 20 salariés / moisPrix annuel
Messagerie simple3 €60 €720 €
Plateforme collaborative12 €240 €2 880 €

Ces montants servent uniquement à apprendre à comparer les coûts. Ce ne sont pas des tarifs commerciaux vérifiés.

Le prix supérieur peut être justifié si l'entreprise utilise réellement les fonctions incluses. Inversement, une boîte IMAP peut parfaitement convenir lorsque le besoin se limite à des courriels synchronisés.
