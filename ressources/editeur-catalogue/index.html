Enregistrement manuel sur GitHub

  1. Clique sur Copier le JSON.
  2. Ouvre le fichier dans GitHub et clique sur le crayon Edit this file.
  3. Sélectionne tout le contenu du fichier (Ctrl+A), puis colle le JSON préparé (Ctrl+V).
  4. Clique sur Commit changes. GitHub Actions publiera ensuite les trois portails.
